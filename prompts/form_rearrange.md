### 매핑 규칙
1. 각 양식 섹션에 가장 의미론적으로 연관된 프레임워크 섹션을 1개 이상 지정
2. 하나의 프레임워크 섹션이 여러 양식 섹션에 중복 배치될 수 있음
3. 연관 섹션이 없으면 빈 배열 []로 표시
4. 섹션 제목과 내용의 의미를 기준으로 판단. 태그나 카테고리가 유사한 것 우선 배치.
5. 한 양식 섹션에 너무 많은 섹션을 배치하지 말 것 (보통 1~2개)

반드시 아래 JSON 형식으로만 응답하세요. 다른 설명 금지.

  ...
}}
