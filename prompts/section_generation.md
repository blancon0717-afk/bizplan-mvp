## 작성 지시

위의 요구사항과 Skills를 적용하여, 사용자 답변 기반으로 **{section_title}** 섹션을 작성하세요.

특별 주의:
1. 답변이 없거나 부족해도 반드시 초안을 작성하되, 아래 두 가지만을 기반으로 추론하세요:
   ① 사용자가 입력한 아이템/서비스명과 설명
   ② 다른 질문에서 충실하게 답변된 내용

   절대 금지:
   - 다른 업종, 다른 아이템, 다른 서비스 내용 임의 삽입
   - 아이템과 무관한 일반적인 내용으로 채우는 것 (예: 아이템이 'AI 사업계획서 솔루션'인데 '일정관리, 이메일 자동분류' 같은 엉뚱한 기능을 추론하는 것)
   - 아이템명조차 언급하지 않고 추상적으로만 작성하는 것

   추론 부분은 반드시 severity=critical 인라인 메모로 'AI 추론 내용입니다. 실제 정보로 교체해주세요'를 달아주세요.
   **content_segments를 빈 배열로 반환하는 것은 절대 금지입니다.**
2. 수치 및 출처 처리 규칙: `[출처 필요]` `[추정값]` `[수치 필요]` 태그를 본문에 절대 삽입하지 말 것. 상세 규칙은 `skills/L1_universal/U01_numbers_with_sources.md` 참조.
3. 해당 섹션 분량은 A4 기준 0.5~1.5페이지가 적절합니다 (양식 전체 분량 고려).
4. 서식 제한 및 본문 서식 규칙 (반드시 준수):
   - `###`, `##`, `#` 마크다운 제목 기호 금지. `**강조**` 별표 금지. `[카테고리명]` 대괄호 레이블 금지.
   - `1. 제목`, `1-1. 제목`, `2-1-1. 제목` 형태의 숫자 섹션 번호 금지 (양식 목차는 시스템이 별도 표시).
   - 표(table)는 허용. 상세 서식 규칙(소제목 구조, 세부항목, 줄간격, 종결어미)은 `skills/L1_universal/BIZPLAN_FORMAT.md` 참조.
5. **시각자료 가이드 표 삽입 규칙**:
   - 시장규모, 성장률, 경쟁사 비교, 기술 구조 등 시각적으로 표현하면 심사에 유리한 내용이 있을 때, 본문 해당 위치에 아래 형식의 표를 삽입할 것
   - 1개 섹션에 최대 2개 표. 표는 관련 본문 내용 바로 아래에 위치. 표 제목은 구체적으로 작성 (예: '글로벌 시장 규모 성장 추이 그래프')
   - 아래 형식을 반드시 준수:

| 시각자료 제목 | 시각자료 제목 |
|-------------|-------------|
| [내용 설명: 어떤 데이터/이미지를 넣어야 하는지] | [내용 설명] |
| 출처: [참고 URL 또는 기관명] | 출처: [참고 URL 또는 기관명] |
| < 이미지 설명/캡션 > | < 이미지 설명/캡션 > |

   - 동일한 표 제목, 동일한 출처, 동일한 내용의 표를 2개 이상 삽입하는 것은 절대 금지
   - 한 섹션 내에서 content_segments 전체를 통틀어 동일하거나 유사한 표가 중복되지 않도록 self-check 후 반환
   - 시각 자료가 전혀 필요 없는 섹션이면 생략하고 사유를 `reasoning`에 명시
6. **inline_suggestions anchor_text 작성 규칙 (절대 준수)**:
   - anchor_text는 반드시 위에서 작성한 content_segments의 text 안에 **글자 하나도 다르지 않게 그대로 존재하는 문구**여야 함
   - 본문에 없는 문구, 요약한 문구, 비슷하지만 다른 문구 절대 금지
   - anchor_text 길이는 10~25자 이내로 제한. 너무 짧으면(5자 이하) 매칭 오류 발생하므로 금지
   - anchor_text는 해당 note(피드백 내용)와 직접 관련된 문장에서 추출할 것. 제목(■로 시작하는 줄)에서 추출 금지
   - anchor_text 선정 순서: ① 피드백 대상 수치/키워드가 포함된 문장 → ② 해당 내용이 서술된 문장 → ③ 관련 단락의 첫 문장
   - 작성 완료 후 self-check: 각 anchor_text를 content_segments 전체 텍스트에서 검색했을 때 정확히 일치하는 문구가 있는지 확인 후 반환
7. **추진 일정표 날짜 작성 규칙 (절대 준수)**:
   - 추진 일정표의 "추진 기간" 컬럼은 반드시 구체적인 날짜 또는 기간으로 채울 것. 공란 절대 금지.
   - 사용자가 인터뷰에서 일정을 언급했으면 그 내용을 반영
   - 언급이 없으면 사업계획서 작성 시점({today})을 기준으로 단계별 소요기간을 합리적으로 추론하여 작성
   - 예시: 1단계(2026.05~2026.07), 2단계(2026.07~2026.09) 형태로 작성
   - 모든 단계가 동일한 기간으로 뭉뚱그려지는 것 금지. 각 단계별 특성에 맞게 다른 기간 설정
   - 협약기간이 명시된 경우 그 범위 안에서 단계별로 배분
8. **출처 표기 규칙 (절대 준수)**:
   - 출처는 외부 데이터(통계청, 시장조사기관, 논문, 뉴스 등)를 인용할 때만 표기
   - "출처: 자체 사업 계획", "출처: 자체 산정 기준" 같은 자체 출처 표기 절대 금지
   - 자체적으로 작성하거나 추론한 내용에는 출처를 달지 말 것
   - 외부 출처가 없는 내용은 출처 없이 서술하면 됨

반드시 JSON 형식으로만 응답하세요. 다른 설명 금지.
