## 작성 지시

위의 요구사항과 Skills를 적용하여, 사용자 답변 기반으로 **{section_title}** 섹션을 작성하세요.

특별 주의:
1. 답변이 없거나 부족해도 반드시 초안을 작성하세요. 아이템/서비스 설명을 기반으로 합리적으로 추론·작성하고, 추론 부분은 severity=critical 인라인 메모로 "AI 추론 내용입니다. 실제 정보로 교체해주세요"를 반드시 달아주세요. **content_segments를 빈 배열로 반환하는 것은 절대 금지입니다.**
2. 수치 및 출처 처리 규칙: `[출처 필요]` `[추정값]` `[수치 필요]` 태그를 본문에 절대 삽입하지 말 것. 상세 규칙은 `skills/L1_universal/U01_numbers_with_sources.md` 참조.
3. 해당 섹션 분량은 A4 기준 0.5~1.5페이지가 적절합니다 (양식 전체 분량 고려).
4. 서식 제한 및 본문 서식 규칙 (반드시 준수):
   - `###`, `##`, `#` 마크다운 제목 기호 금지. `**강조**` 별표 금지. `[카테고리명]` 대괄호 레이블 금지.
   - `1. 제목`, `1-1. 제목`, `2-1-1. 제목` 형태의 숫자 섹션 번호 금지 (양식 목차는 시스템이 별도 표시).
   - 표(table)는 허용. 상세 서식 규칙(소제목 구조, 세부항목, 줄간격, 종결어미)은 `skills/L1_universal/BIZPLAN_FORMAT.md` 참조.
5. **시각자료 가이드 표 삽입 규칙**:
   - 시장규모, 성장률, 경쟁사 비교, 기술 구조 등 시각적으로 표현하면 심사에 유리한 내용이 있을 때, 본문 해당 위치에 아래 형식의 표를 삽입할 것
   - 1개 섹션에 최대 2개 표. 표는 관련 본문 내용 바로 아래에 위치. 표 제목은 구체적으로 작성 (예: '글로벌 시장 규모 성장 추이 그래프')
   - 아래 형식을 반드시 준수:

| 시각자료 제목 | 시각자료 제목 |
|-------------|-------------|
| [내용 설명: 어떤 데이터/이미지를 넣어야 하는지] | [내용 설명] |
| 출처: [참고 URL 또는 기관명] | 출처: [참고 URL 또는 기관명] |
| < 이미지 설명/캡션 > | < 이미지 설명/캡션 > |

   - 시각 자료가 전혀 필요 없는 섹션이면 생략하고 사유를 `reasoning`에 명시
