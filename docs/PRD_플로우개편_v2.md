## 2. 서비스 플로우 변경

### 현재 플로우
```
기업정보 입력 → 지원사업 추천/선택 → 인터뷰 10문항 → 양식 기반 초안 생성 → 피드백 → DOCX
```

### 변경 후 플로우
```
1단계: 기업정보 입력 (아이템 설명, 업력, 청년/지역 여부)
2단계: 인터뷰 10문항 답변
3단계: 기본 프레임워크 초안 생성
       (4개 대섹션 / DRAFT_WRITING_GUIDE 기준, 양식 무관)
4단계: 초안 열람 + 인라인 피드백 확인 및 수정
5단계: 지원사업 추천 + 양식 선택
6단계: 양식 변환 (선택한 양식 기준으로 재배치)
7단계: 최종 결과 열람 + DOCX 다운로드
```

## 3. 핵심 기능

| 번호 | 기능명 | 설명 | 우선순위 |
|---|---|---|---|
| 1 | 프레임워크 초안 생성 | DRAFT_WRITING_GUIDE 4개 대섹션 기준으로 초안 생성. 양식 YAML 미사용 | 높음 |
| 2 | 초안 열람 및 인라인 피드백 | 생성된 초안 열람 + inline suggestion 확인 | 높음 |
| 3 | 지원사업 추천 (초안 생성 후) | 프레임워크 초안 바탕으로 적합한 지원사업 추천 | 높음 |
| 4 | 양식 선택 | 추천 결과 중 원하는 지원사업 양식 선택 | 높음 |
| 5 | 양식 변환 | 프레임워크 초안 → 선택한 양식 섹션 구조로 재배치 (부자연스러운 문구만 수정) | 높음 |
| 6 | DOCX 다운로드 | 최종 변환된 사업계획서 다운로드 | 높음 |

## 4. 기능 상세

### 4-1. 프레임워크 초안 생성

- **입력**: 인터뷰 10문항 답변
- **처리**: DRAFT_WRITING_GUIDE의 4개 대섹션(1~4)을 기준으로 Claude 생성. 양식 YAML 미사용.
- **출력**: 섹션별 초안 + inline_suggestions
- **API**: Claude Haiku (기존 call_claude 래퍼)

### 4-2. 양식 변환

- **입력**: 프레임워크 초안 + 선택한 양식 코드 (예: `initial_package`)
- **처리**: 기존 양식 YAML의 섹션 구조를 읽어, 프레임워크 초안의 내용을 해당 섹션에 맞게 재배치. 흐름이 부자연스러운 경우 문구·제목만 수정.
- **출력**: 양식 맞춤 사업계획서
- **API**: Claude Haiku

## 7. 성공 기준

1. 기업정보 입력 → 인터뷰 → 기본 프레임워크 초안이 4개 대섹션으로 생성됨
2. 생성된 초안에 인라인 피드백(메모)이 표시됨
3. 초안 완성 후 지원사업 추천이 표시되고 양식 선택 가능
4. 양식 선택 후 해당 양식의 섹션 구조로 재배치된 결과가 생성됨
5. 최종 결과를 DOCX로 다운로드 가능
6. 신규 세션 데이터 정상 저장 및 재접속 시 이어보기 가능

---

## 8. 데이터 처리

- **기존 세션 (구버전)**: 호환 불필요. 신경 쓰지 않음.
- **신규 세션 (신버전)**: 프레임워크 초안 + 변환 결과 모두 저장. 재접속 시 이어서 볼 수 있어야 함.
