## 핵심 기능 3가지

### 기능 ① AI 소재 자동 분류 모듈

### 기능 ② 공급자-수요자 실시간 매칭 플랫폼

### 기능 ③ 이력 추적 및 ESG 인증 리포트 자동 생성
- 수거 → 분류 → 거래 전 과정을 블록체인 기반으로 기록
- 수요 기업이 ESG 공시에 활용 가능한 **재활용 원료 사용 인증 리포트** 자동 발급
- 국내 K-ESG, EU CSRD 대응 포맷 제공 (규제 연동 차별화)

## 7-2. 진입장벽 3대 레이어

### Layer 1. 데이터 해자 (Data Moat) — 가장 강력한 방어선

```
폐그물 소재 특성 데이터는 공개 데이터셋 전무

→ 누적 분석 건수가 많을수록 모델 정확도 향상 (강화학습 구조)
→ 후발 진입자는 최소 1~2년 데이터 축적 격차 발생
```

|----------------|------|

### Layer 3. 규제·인증 선점 (Regulatory Moat)

```
해양환경관리법 개정 (2023) → 폐어구 수거 의무화 강화
→ 수거된 폐그물의 품질 기록·보고 의무 부상 예정 [출처 필요]
→ 본 플랫폼의 자동 리포트 기능이 법적 요건 충족 도구로 포지셔닝 가능
→ 선제 인증·등록 시 조달·수협 납품 우선권 확보
```

**선점 실행 계획**
