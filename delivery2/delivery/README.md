**블랜 × 알파브라더스 그룹 — 데이터 기반 창업 지원 분석 자료**

## 핵심 수치 요약

### 분석 규모
| 항목 | 수치 |
|---|---|
| 분석한 사업계획서 | 739건 |
| 대상 창업 프로그램 | 10개+ (예창·초창·창도·청창사·창중·딥테크 등) |
| 서류 심사위원 피드백 | 123건 / 21개 기업 |
| 발표 Q&A | 508건 / 104개 기업 |
| 서류↔발표 교차 분석 가능 | 38개 기업 |
| 분석 기간 | 2022~2026 |
| 서류 합격률 | 약 77% |
| 최종 합격률 | 약 22% |

### 통계 모델 성능
| 모드 | 대상 | AUC |
|---|---|--:|
| 7개 주요 프로그램 | n=571건 | **0.668** |
| 전체 프로그램 | n=739건 | **0.642** |

> AUC 0.5 = 랜덤 / 1.0 = 완벽 예측. 0.64~0.67은 "의미 있는 예측력" 수준.

### 합격을 결정하는 핵심 피처 (통계 유의미)

| 피처 | 방향 | 배점 | p값 | 해석 |
|---|:--:|:--:|--:|---|
| 누적 투자 유치 | ↑합격 | 5점 | 0.004 | 외부 투자 받은 이력 있으면 강한 합격 신호 |
| 필수 재료 공급처 네트워크 | ↑합격 | 5점 | 0.008 | 독점 공급망 확보 = 실행력 증명 |
| 제조 전문 인력 보유 | ↑합격 | 4점 | 0.015 | 제조업 아이템에서 특히 강한 신호 |
| 소재지 + 주관기관 일치 | ↑합격 | 4점 | 0.043 | 지역 프로그램 지원 시 주소 확인 필수 |
| MOU 보유 개수 | ↑합격 | 3점 | 0.071 | 많을수록 합격 가능성 상승 |
| 투자의향서 확보 | ↑합격 | 3점 | 0.092 | 외부 검증 신호 |

> ⚠️ **반직관 신호**: FGI(포커스그룹인터뷰), 비즈니스모델 다양화, 경력 증빙 서류는
> 기술 중심 프로그램에서 오히려 감점 패턴 확인. 자세한 내용은 `01_사업계획서_작성가이드.md` 참조.

## 파일별 사용 가이드

### `guides/01_사업계획서_작성가이드.md`
사업계획서를 처음 쓰거나 기존 계획서를 점검할 때.

**추천 순서:**
1. `작성 전 체크` — 아이템이 합격 가능한 방향인지 먼저 확인
2. `8대 구성 섹션` — 섹션별 체크리스트를 채우며 작성
3. `최종 자가 점검 체크리스트` — 16개 항목 중 8개 미만이면 재작성 권장
4. `보강 자료` — MOU·투자의향서·수요처 계약서 우선 확보 (★★★ 항목)

---

### `guides/02_심사위원피드백_스킬.md`
심사위원이 실제로 어떤 말을 하는지 파악하고 우리 계획서 약점 점검.

**구성:**
- **공통 레이어** — 프로그램 무관하게 모든 계획서에 적용되는 16개 지적 유형
- **프로그램별 레이어** — 지원할 프로그램 섹션만 펼쳐서 확인
- 21개 기업의 **실제 심사위원 피드백 문장 전문** 포함

---

### `guides/03_아이템_키워드_전략.md`
아이템 설명 문구와 제목을 어떻게 써야 하는지.

**핵심 내용:**
- 합격 사례 8개 키워드 클러스터
- 합격률 높은 제목 패턴 A~E
- 불합격 키워드 패턴 (쓰지 말아야 할 표현 포함)

---

### `guides/05_발표Q&A_스킬.md`
발표 심사에서 심사위원이 어떤 질문을 하는지 파악하고 대비.

**구성:**
- **태그별 질문 빈도표** — 21개 유형 × 비율 (제품경쟁력 17.7%, 기술 16.3%, 수익구조 9.4% 등)
- **태그별 실제 질문 예시** — 최대 8건씩 질문+답변 전문 수록
- **서류↔발표 교차 분석** — 서류 피드백 + 발표 Q&A 모두 있는 38개 기업 목록

> 서류 합격 후 발표 준비 시 이 파일을 집중적으로 활용.

### `system/04_피드백솔루션_설계.md` + `data/`
사업계획서를 자동으로 피드백하는 시스템 구현 시 사용.

**`data/rubric_all_clean.json`** — 스코어링 엔진 구현용
```
피처명, 합격 방향(+/-), 배점(1~5), p값, OR값 포함
→ 사업계획서 텍스트에서 피처 감지 → 점수 산출
```

**`data/feedback_pairs.json`** — LLM few-shot 예시 데이터
```
기업명, 아이템명, 사업명, 태그, 심사위원피드백 포함 (123건)
→ 유사 사례 검색 후 LLM 컨텍스트에 삽입
→ "biz_plan_text" 필드는 향후 PDF 추출 연동 시 채움
```

## 주의사항

- 분석 대상은 블랜이 운영 지원한 사업계획서에 한정. 전체 창업 생태계 대표성 없음.
- AUC 0.64~0.67 수준 — 예측 참고용이며 합격을 보장하지 않음.
- 심사위원 피드백은 21개 기업 기준 — 추가 데이터 누적 시 정확도 향상 가능.
- 반직관 피처는 프로그램 유형별 검증 후 적용 권장.
