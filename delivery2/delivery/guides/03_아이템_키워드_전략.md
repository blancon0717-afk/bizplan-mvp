# 합격 아이템 키워드 전략 — 사업계획서 자동화 참고

> 출처: project99 회귀분석 결과 (n=739, 전체 사업유형) + 합격/불합격 아이템명 특이성 키워드 분석
> 업데이트: 2026-04-25 (신규 프로그램 포함 — 에코스타트업·혁신패키지·딥테크 등)

---

## 합격 클러스터 8가지

### 클러스터 1 — 수치 구체화 (가장 강한 신호)

고객·사회 이익으로 직결되는 수치. 규모 과시 수치는 불합격 패턴.
친환경 프로그램에서는 환경 효과도 고객 이익처럼 수치화하면 합격.

**합격 패턴**
```
[숫자]% [절감/개선/감소]   물류비 40% 절감 / VOCs 배출 80% 감소 / 에너지 60% 절감
[숫자]배 [차별점]           이형성 500% 향상 / 2배 강도 압착기술 / 사용수명 300% 향상
[숫자]회/건 [검증]         1,000회 안정성 검증 / 50μm 결함 검출 98% 정확도
[숫자]일 [기간단축]         배송기간 14일 단축
[숫자]% [환경효과]         낙엽 부피 80% 감소 / 탄소 70% 절감 / 빛 공해 40% 감소
```

**불합격 패턴 (피할 것)**
```
규모 과시형   50,000건 상담 DB / 37곳 네트워크 / 시제품 100개 개발
```

---

### 클러스터 2 — 독자 기술 명사화

범용 기술 수식어("AI 기반", "빅데이터")는 합격/불합격 양쪽에 동일 빈도 등장.
기술을 고유명사로 명명했는지 여부가 차이.

**합격 패턴 — 기술에 이름을 붙임**
- R-CNN 딥러닝 기반 AI 판단
- SOLAMIC X-free / 나노링크 도킹시스템
- 익반죽 공법 / 친환경 VNT 공법
- 국산화 PUPSIT SKID
- Discovery 인터페이스 큐레이션 알고리즘
- DKT 기술 기반 6단계 지식 측정
- EcoGuard 잉크 / ECO 그린 스마트 가로등

**불합격 패턴 — 기술 설명만 있고 이름 없음**
- AI 기반 업무 문의 통합뷰
- 비지도학습 딥러닝 기반 이상 탐지
- 혼합롤링 기술 / 3 in 1 복합필터

> **룰**: 기술에 이름을 붙이면 합격, 설명만 하면 불합격.

---

### 클러스터 3 — 비즈니스 모델 구조 명시

수익 구조를 레이어로 명시. 기능 나열과 다름.

**합격 패턴**
```
B2B + B2C 이중 플랫폼
3단계 구독형 수익 모델
풀필먼트 자동화 + 다채널 API
제조사 진출 리스크 제로 구조 + 전용 수수료 모델
O&M 통합관리 프로세스
```

**불합격 패턴**
```
다채널 통합 판매관리     → 기능 나열
다중 채널 통합           → 기능 나열
당일 출고 배송 프로세스  → 속도만 강조, BM 없음
```

### 클러스터 4 — 틈새 시장 좌표 명확화

합격군 타깃은 극도로 좁음. 불합격군은 흔하거나 과잉 경쟁 시장.

| 합격 (좁고 구체적) | 불합격 (넓거나 과잉 경쟁) |
|---|---|
| 어린이집 특화 풀케어 | 유아 특화 에듀테크 |
| 재고처리 전문 커머스 | 소상공인 맞춤 인플루언서 매칭 |
| 외국인 의료관광 통합 플랫폼 | 반려동물 질병 조기 진단 |
| 공사업체 특화 ERP 연동 | 반려동물 자동 배변판 |
| 보신탕 업종 전환 지원 | 웨어러블 헬스케어 일반 |
| 산업용품 전문 2,000개 세분류 | 교육키트 연계 비즈니스 모델 |

**경보 키워드 (다수 프로그램에서 불합격 반복)**
- `소상공인 맞춤형`
- `반려동물 + 헬스케어/모니터링` (자동 배변판 포함)
- `웨어러블 헬스케어 모니터링`
- `AI 생산관리 시스템`
- 단일 희귀 원료: `토종보리수`, `보이차 후발효`, `스피루리나`, `베타글루칸 버섯균사체`

### 클러스터 5 — 대체/전환 포지셔닝

기존 방식을 명시적으로 대체한다고 선언하는 프레임.

**합격 패턴**
```
[기존 시스템] 대체     아마존 FBA 대체 서비스 FBR
[기존 소재] 완벽 대체  불소 코팅제 완벽 대체재 / 플라스틱 완전 대체
[기존 한계] 극복       도수치료 한계 극복 솔루션
[관행] 제거            브로커 제거를 통한 투명성 강화
[업종] 전환 지원       보신탕 업종 전환 지원
```

---

### 클러스터 6 — 국산화/완전대체 선언 (신규 — 딥테크·에코·소재 계열)

수입품·유해물질의 국산화·완전대체 선언. "더 좋다"가 아니라 "완전히 대신한다".

**합격 패턴**
```
국산화 [수입품명]       국산화 PUPSIT SKID (수입 의존도 100% → 국산화)
[유해물질] FREE + 대체재  PFAS FREE 100% / 불소 코팅제 완벽 대체재
[소재] 100% 대체        플라스틱 완전 대체 / 쌀 100% 글루텐프리
국내 최초 [조합]        홍삼+아르기닌 국내 최초 배합
```

**불합격 패턴 (기능 조합 vs 대체 선언의 차이)**
```
3 in 1 복합필터     → 대체 선언 없이 기능 조합만
혼합롤링 기술       → 무엇을 대체하는지 불명확
```

---

### 클러스터 7 — 외부 공인 신뢰성 (신규 — 소공인·혁신패키지·소재 계열)

내부 주장이 아닌 외부 기관·전문가 검증을 키워드로 명시.

**합격 패턴**
```
인증기관    FDA 승인 / 식약처 인정 기능성 / 국내 최고 연구기관 공동개발
전문가 개발  피부과 전문의 개발 / 약사 직접 개발 / 13년 누적 강의 연계
파트너십    동남아 5개국 물류센터 MOU / 보험사-공업소 매칭 플랫폼
```

**불합격 패턴 (내부 증거만 제시)**
```
특허 보유        → 내부 증거
시제품 100개 개발 → 내부 진행 현황
기술임치         → 내부 절차
```

---

### 클러스터 8 — AI × 도메인 조합 명명 (신규 — 딥테크 계열)

`AI`만 쓰면 불합격. `AI + 측정 대상 명사`를 명확히 조합하면 합격.

**합격 패턴**
```
[AI/기술명] + [측정/분석 대상] + [결과 수치]

드론 AI 기반 태양광패널 결함 분석 → 패널 1개 단위 실시간 O&M
Vision AI 기반 광고 효과 → 보행자 시선 분석 자동화
비전 센서 기반 자동 피드백 제어 → 국산화 오비탈 자동용접기
DKT 기술 기반 6단계 지식 측정 → 메타인지 AI 성적처리
메디맵 AI + OCR → 외국인 의료관광 다국어 챗봇
```

**불합격 패턴**
```
AI 기반 업무 문의 통합뷰    → 측정 대상 불명확
AI 생산관리 시스템          → 범용
비지도학습 딥러닝 이상 탐지 → 도메인 특화 없음
```

## 제목 구성 5가지 패턴

### 패턴 A — 대체 선언형
```
[기존 시스템/관행] + 대체/극복/제거 + [핵심 기술 고유명]

예) 아마존 FBA를 대체하는 동남아 특화 풀필먼트 플랫폼 FBR
예) 브로커 없는 외국인 의료관광 — 다국어 컨시어지 통합 플랫폼
```

### 패턴 B — 수치+시장+솔루션형
```
[수치 차별점] + [타깃 시장] + [솔루션 명]

예) 물류비 40% 절감, 배송 14일 단축 — 동남아 5개국 거점 풀필먼트
예) VOCs 배출 80% 감소 — 번짐 방지 나노 실리카 기반 수성잉크 EcoGuard
```

### 패턴 C — 기술 고유명+틈새 시장형
```
[독자 기술명] + [극소 타깃] + [가치 명시]

예) 익반죽 공법 기반 쌀 100% 글루텐프리 베이커리 — HMR 특화
예) 국산화 PUPSIT SKID — 제약 무균 공정 자동화 1/10 가격 실현
```

### 패턴 D — 국산화/완전대체 선언형 (소재·딥테크 특화)
```
[기존 수입품/유해물질] + 완벽 대체 + [독자 기술명] + [수치 성능]

예) 불소 코팅제 완벽 대체재 SOLAMIC X-free — 이형성 500% 향상, PFAS FREE 100%
예) 수입 의존 오비탈 용접기 국산화 — 비전 센서 자동 피드백 제어
```

### 패턴 E — AI×도메인 조합형 (딥테크 특화)
```
[AI/기술명] + [측정 대상 명사] + [수치 결과]

예) Vision AI 기반 옥외광고 보행자 시선 분석 — 현수막 디지털화 대체
예) 드론 AI 태양광패널 결함 검출 — 패널 1개 단위 실시간 O&M
```

## 제목 자동 검증 체크리스트

### 합격 신호 (해당 항목 수 → 점수화 가능)
- [ ] 고객·환경 이익 수치 포함 (절감/개선/감소 수치)
- [ ] 기술에 고유명사 있음 (공법명/브랜드명/약어)
- [ ] 타깃이 업종/상황 수준으로 좁게 정의됨
- [ ] 기존 방식 대비 대체/극복/제거/국산화 포지셔닝
- [ ] B2B/B2C/B2G 수익 구조 명시
- [ ] 외부 기관 인증 또는 전문가 개발 명시 (FDA/식약처/연구기관/전문의)

### 불합격 경보 (해당 시 감점 or 경고)
- [ ] "AI 기반" 단독 수식어 (측정 대상 명사 없이)
- [ ] "통합/올인원/원스톱" 3개 이상 조합
- [ ] 소상공인 + 맞춤형 조합
- [ ] 반려동물 + 헬스케어/모니터링 조합
- [ ] 수치가 규모 과시 목적 (건수/업체수/시제품 개수)
- [ ] 단일 희귀 원료 강조 (토종보리수/보이차/스피루리나 등)
- [ ] 기능 나열형 조합 (X in 1 / 다중 채널 통합)
