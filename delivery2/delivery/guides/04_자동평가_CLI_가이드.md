# 사업계획서 자동 평가 CLI 가이드

**score_plan.py — 합격 확률 산출 + 개선 피드백 자동 생성**

---

## 개요

`score_plan.py`는 사업계획서 PDF(또는 텍스트)를 입력받아:

1. Claude Haiku로 50개 루브릭 피처를 자동 판정
2. 815건 합격 데이터로 학습한 Lasso 회귀 모델로 합격 확률 계산
3. 약한 피처에 대한 구체적 개선 피드백 출력
4. 마크다운 리포트 자동 저장

---

## 설치 전제 조건

- Python 3.10+
- `.env` 파일에 `ANTHROPIC_API_KEY` 설정 완료
- `pip install -r requirements.txt` 완료

자세한 설치 방법은 `HANDOFF.md` 참조.

---

## 기본 사용법

### PDF 파일 평가

```bash
python score_plan.py 사업계획서.pdf --program 예비창업패키지
```

### 텍스트 직접 입력

```bash
python score_plan.py --text "아이템 설명 및 사업 내용 전문..." --program 초기창업패키지
```

### 지원 프로그램 목록

`--program` 에 입력하는 값은 사업계획서 상단에 기재된 지원사업명과 일치시키는 것을 권장:

| 프로그램 | `--program` 입력 예시 |
|---|---|
| 예비창업패키지 | `예비창업패키지` |
| 초기창업패키지 | `초기창업패키지` |
| 창업도약패키지 | `창업도약패키지` |
| 청년창업사관학교 | `청년창업사관학교` |
| 창업중심대학 | `창업중심대학` |
| 딥테크 | `딥테크` |

## 전체 옵션

```
python score_plan.py [PDF경로 또는 --text "텍스트"] [옵션]

위치 인수:
  plan_path             평가할 PDF 파일 경로 (--text 사용 시 생략)

필수 옵션:
  --program TEXT        지원 사업명

선택 옵션:
  --text TEXT           PDF 대신 텍스트 직접 입력
  --mode {7types,all}   평가 모델 선택 (기본: 7types)
                          7types: 7개 주요 프로그램 전용 (n=573, AUC 0.678) ← 더 정확
                          all:    전체 프로그램 통합 (n=749, AUC 0.640)
  --organizer TEXT      주관기관명 (지역 일치 피처 판정에 활용)
  --no-save             리포트 파일 저장 안 함
```

## 결과 해석 방법

### 합격 확률 읽기

| 확률 구간 | 해석 |
|---|---|
| 80% 이상 | 현재 계획서로도 충분한 수준 |
| 60~79% | 1~2개 핵심 피처 보강 시 경쟁력 확보 |
| 40~59% | 복수 피처 동시 보강 필요 |
| 40% 미만 | 계획서 구조 전면 재검토 권장 |

> 기준치: 서류 합격률 77% / 최종 합격률 22%
> 기준치보다 높으면 데이터 평균 이상, 낮으면 이하.

### 피처 우선순위

피드백에 나오는 피처는 OR(오즈비)와 p값 기준으로 정렬됩니다.
위에 있을수록 합격에 미치는 영향이 크므로 우선 보강하세요.

**합격에 가장 강한 영향을 주는 피처 TOP 5:**

| 순위 | 피처 | 보강 방법 |
|---|---|---|
| 1 | 누적 투자 유치 금액 | 엔젤·VC 투자 이력 명기 |
| 2 | 필수 재료 공급처 네트워크 | 독점 공급 계약서 확보 |
| 3 | 제조 전문 인력 보유 | 제조 담당 팀원 이력 상세 기재 |
| 4 | 소재지·주관기관 일치 | 지역 프로그램 지원 시 사업장 주소 확인 |
| 5 | MOU 보유 개수 | 파트너사 협약서 최소 1건 |

## 실용 팁

### 반복 평가로 점수 올리기

1. 처음 실행 → 약점 피처 확인
2. 계획서 해당 섹션 보강 (구체적 수치·증빙 추가)
3. 재실행 → 확률 변화 확인
4. 목표 확률 달성까지 반복

### 프로그램별 비교

같은 계획서로 여러 프로그램을 비교해 지원 전략 수립:

```bash
python score_plan.py plan.pdf --program 예비창업패키지 --mode 7types
python score_plan.py plan.pdf --program 초기창업패키지 --mode 7types
python score_plan.py plan.pdf --program 청년창업사관학교 --mode 7types
```

## 주의사항

- AUC 0.678 — 통계적 참고값이며 합격을 보장하지 않습니다.
- 암호화된 PDF는 텍스트 추출 불가 → `--text` 옵션으로 직접 붙여넣기 사용.
- PDF가 스캔 이미지인 경우 추출 품질이 낮아질 수 있음.
- 피처 판정은 Claude Haiku 호출 비용이 발생합니다 (건당 약 $0.001).
