# 용도
사용자 답변을 읽고 **업종 성격을 자동 판별**, 해당 업종에서 강조해야 할 포인트를 섹션 생성 시 반영.

# 업종 판별 시그널

## 딥테크 / 기술 창업
- 답변에 "특허·TRL·PoC·연구개발·논문" 등장
- 기술 원리 설명이 상세
- 예: 바이오, IoT, 로봇, 소재, AI 알고리즘
- **강조 포인트**:
  - 기술 원리 3단계 분해
  - 특허 청구항 → 사업 직결성
  - TRL 대신 "실증 증거 + 제3자 검증"
  - 확장 경로: 단일제품 → 기술 플랫폼 → 라이선싱
  - IPO/M&A 벤치마킹 구체화

## SaaS / B2B 소프트웨어
- 답변에 "구독·SaaS·MRR·ARR·리텐션·사용자" 등장
- 예: 업무 자동화, 데이터 분석, 협업툴
- **강조 포인트**:
  - MRR/ARR 및 성장률
  - 리텐션·이탈률·NPS
  - 고객당 LTV vs CAC
  - 벤치마킹 (채널톡, 오피스24 등)
  - 3트랙: 구독 + 프로 요금제 + 데이터·API 판매

## 제조 / 하드웨어
- 답변에 "공장·OEM·생산·원재료·BOM" 등장
- 예: 가전, 장비, 부품
- **강조 포인트**:
  - OEM 파트너 구체 기업명
  - BOM·원가 구조
  - 공급망 리스크 대응
  - 인증 (KC, CE, UL 등) 취득 계획
  - 재료 공급처 확보

## 바이오 / 헬스케어
- 답변에 "임상·GMP·MFDS·FDA·식약처" 등장
- 예: 의약품, 의료기기, 건강기능식품
- **강조 포인트**:
  - 임상 단계·IND 신청
  - 규제 기관 소통 내역
  - GMP 인증·제조시설
  - 의료/약학 자문위원
  - 리얼월드 데이터

## 콘텐츠 / 플랫폼
- 답변에 "크리에이터·IP·팬덤·광고·수수료" 등장
- 예: 콘텐츠 제작, 커머스 플랫폼
- **강조 포인트**:
  - 월 활성 사용자(MAU)
  - 광고·커머스·구독 복합 BM
  - IP 파이프라인
  - 크리에이터·파트너 네트워크

# 판별 알고리즘 (LLM 지시)
1. 사용자 답변 전체를 읽고 위 시그널 단어 빈도 확인
2. 상위 2개 업종 카테고리 후보 선정 (하이브리드 허용)
3. 각 후보에 신뢰도 (0~100) 부여
4. 최상위가 60 이상이면 단일 업종, 그 이하면 복합 업종
5. 결과를 JSON으로 반환:
```json
{
  "primary_industry": "딥테크",
  "primary_confidence": 85,
  "secondary_industry": "SaaS",
  "secondary_confidence": 40,
  "reasoning": "특허·알고리즘·PoC 언급과 구독 모델 병존"
}
```

# 주의
- 사용자 답변에서 업종 시그널이 부족하면 (모든 신뢰도 < 40) "일반" 업종으로 처리하고 기본 원칙만 적용
- 확정 편향 방지: 하나의 시그널만으로 판단하지 말 것
