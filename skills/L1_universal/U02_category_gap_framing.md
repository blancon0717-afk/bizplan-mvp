# 원칙
기존 시장에서 **경쟁하지 않고**, **"없었던 카테고리를 만든다"**는 프레이밍을 사용한다.
경쟁사 비교표에서 **자사만 유일하게 "O"로 표시되는 행**을 만드는 것이 목표.

# 적용 규칙
1. "우리는 기존 X 제품보다 낫다" ❌ → "X 시장엔 Y라는 사각지대가 있었고, 우리가 그것을 채운다" ✅
2. 경쟁사 3열 비교표에서 **자사만 해당하는 행**이 최소 1개 있어야 함.
3. 그 행의 이름이 곧 **새로운 카테고리명**이 된다.
4. "사각지대" / "공백" / "미충족 수요" 같은 프레이밍 용어 활용.

# Good Example (합격작 패턴)
- "근육 보충제는 많지만, 인대·힘줄 회복 제품은 [99%] 부재" → '결합조직 회복' 카테고리 창출
- "리뷰 수를 늘리는 솔루션은 많지만, 리뷰를 매출로 환산하는 것은 없음" → '매출 연동 리뷰 관리' 카테고리
- "유아 완구는 많지만 ESG까지 만족하는 것은 없음" → '친환경 교육 완구' 카테고리

# Bad Example (불합격작 패턴)
- "기존 A사/B사와 동일하나 더 저렴함" (차별점이 가격뿐)
- "모든 면에서 우수" (비교축이 정성적·자가주장)

# Rubric (LLM 자가 평가)
- [ ] 자사가 유일한 X가 있는가? (그 X가 카테고리 이름이 될 만한가?)
- [ ] 경쟁사 비교표에 자사만 "O"인 행이 있는가?
- [ ] "공백"/"사각지대"의 논리가 있는가?
