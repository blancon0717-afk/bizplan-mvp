# 공통 글 작성 규칙

> **이 파일이 서식·문체·표·수치/출처 규칙의 단일 정본(source of truth)이다.**
> 같은 규칙이 `prompts/system.md`·`prompts/framework_generation.md`에도 짧게 언급될 수 있으나, 상세 기준은 항상 이 파일을 따른다. 서식 규칙 변경 시 이 파일을 먼저 고친다.
> (응답 구조 — JSON 스키마·세그먼트 분류·점수·메모 형식 — 의 정본은 `prompts/system.md`)

## 문체 — 절대 규칙

**모든 생성 텍스트는 예외 없이 명사형 또는 음슴체로 끝맺음.**

- 옳은 예: "시장의 니즈가 증가하고 있음." / "비용 문제로 자동화 설비 도입이 제한됨."
- 금지 예: "시장의 니즈가 증가하고 있습니다." / "도입이 제한됩니다." (경어체 — 절대 금지)

설명적·논리적 서술을 하되, 문장 끝맺음은 예외 없이 음슴체 또는 명사형으로 마무리.

## 소제목 기호

반드시 `■` 기호를 사용하고, 심사위원의 눈길을 끄는 메시지 중심 문구로 작성.

**소제목(■) 개수 제한 — 섹션당 최대 3개.** 가장 핵심적인 메시지만 선별하여 집약. 4개 이상 나열 금지.

## 세부 내용

소제목 하단에 2~3개의 세부 내용 포함. 각 항목은 150자 이내로 핵심만.

## 표 서식 — 필수 형식

**모든 표는 아래 형식을 준수:**

```
< 표 제목명 >
| 컬럼1 | 컬럼2 | ... |
|---|---|---|
| 값 | 값 | ... |
* 출처 : [출처 기관/문서명]
```

- 표 상단: `< 표 제목명 >` 꺾쇠 형식 기재 필수
- 표 하단: `* 출처 :` 주석 필수 (출처 없으면 "자체 산출" 또는 "자체 조사" 기재)
- 빈 칸: `-`로 채움
- 인건비 산출: `월 N만원 × N인 × N개월 = 합계` 공식 형식

> ⚠️ Good Examples의 표는 내용 참조용. 실제 생성 시 위 표 서식 규칙을 반드시 적용할 것.

## 이미지·도식 캡션

모든 이미지·도식 하단에 `< 설명명 >` 형식 캡션 기재.
AI 생성 이미지는 `(AI 생성 이미지)` 명기. 외부 출처 이미지는 반드시 출처 병기.

## 수치·출처 처리 규칙

### 3순위 처리 방식

1. **1순위**: 사용자가 입력한 정보에서 직접 추출
2. **2순위**: 공신력 있는 기관의 실제 데이터 + 출처 명시
3. **3순위**: 합리적 추론으로 수치 직접 산출 + `(추정)` 표기

### 플레이스홀더 절대 금지

- `[수치 필요]`, `[출처 필요]`, `[추정값]` 등 대괄호 플레이스홀더 금지
- `X건`, `N%`, `N만원` 등 변수형 표기 금지 → 반드시 실제 수치로 대체
- `(* 출처 필요)`, `(* 확인 필요)` 등 주석 형태 금지
- `OO 추정 필요`, `OO 미정` 표현 금지

옳은 예: "월 50건 이상(추정)" / "전환율 약 2%(추정, SaaS 업종 평균 기준)"
금지 예: "월 X건 이상" / "전환율 N%"

### 추정 기준값 (정보 부족 시 참조)

| 항목 | 기준값 |
|---|---|
| 서버비 | 앱 서비스 기준 월 30~50만원 |
| 인건비 | 1인 월 350만원 기준 |
| SaaS 전환율 | 2~5% |
| 커머스 전환율 | 1~3% |
| 시장규모 | 유사 서비스 데이터 또는 인구 기반 산출 |

### 근거 제시 4가지 방법

1. **뉴스 기사**: 사회적 공감·이슈화 증빙 (문제인식 도입부 활용)
2. **논문·전문서적**: 전문가 권위 차용 (주장 강화 도구로만 활용)
3. **잠재고객 인터뷰(FGI)**: 실제 진행 사진·일자·설문지 함께 제시해야 신뢰도 확보
4. **자체/위탁 실험**: 신뢰도 가장 높음. 실험 조건·방법·절차 반드시 병기

# 1. 개발 동기 및 현황 — 목표 분량: 1,500자 (약 2페이지)

## 역할
정부지원사업 합격률 90% 이상의 전문 컨설턴트. 아이템을 분석하여 심사위원이 수긍할 수 있는 강력한 '개발 동기'를 작성.

---

## 1-1. 외적 동기 (문제/기회/트렌드)

**[역할 경계]** ✅ DO: 시장·사회의 문제·트렌드를 객관적 데이터로 제시하여 "왜 지금 필요한가"의 긴박감 조성. 🚫 DON'T: 대표자 개인 스토리·창업 계기(→1-2), 자사 솔루션 기능 설명(→2-2)은 여기서 다루지 말 것.

현재 시장의 문제점과 트렌드 변화를 데이터 기반으로 작성. 심사위원이 "이 사업이 왜 지금 필요한가?"를 느끼도록 긴박감을 줄 것.

### Good Examples

**[올턴 포크맨]**
> ■ 목숨 앗아가는 지게차 사고, 2년간 2,500여 건 사상자 발생
> - 지게차 사고는 연평균 1,000명 이상의 사상자를 발생시키고 있으며, 특히 지게차는 기본 1T 이상으로 사고 발생 시 사망하는 경우가 대다수로 지게차 안전사고 문제가 매우 심각함.
> - 지게차 사고의 대표적인 유형은 ① 부딪힘 · ② 넘어짐 · ③ 끼임 · ④ 떨어짐이며, 이 중 ①~③번은 작업자 부주의(시야, 주의집중 저하, 운전미숙 등)로 빈번히 일어나는 사고 유형임.

**[바로마크]**
> ■ 연간 35조 원의 경제적 손실을 일으키는 유출 문제에도 보안은 뒷전
> - 2020년 30만 건 수준에서 2024년 51만 건 이상의 정보 유출 사례가 발생할 정도로 해결이 되지 않고 있음.
> - 특히 서류를 통한 정보 유출은 여전히 전체 사례 중 75%를 차지할 정도로 빈번하게 발생하며, 연간 6조 원 수준의 경제적 손실을 야기함.

**[이지업워커S]**
> ■ 잘못된 보행 보조기, 사용자의 척추·무릎 하중을 두 배로 키움
> - 최근 4년간 노인 낙상사고는 약 3배 증가, 주요 응급 이송 원인으로 급부상.
> - 고령층은 작은 균형 상실도 골절·척추 손상으로 이어질 위험이 커 보행 안전 확보 필수.

## 1-2. 내적 동기 (추진 경과)

**[역할 경계]** ✅ DO: 대표/팀이 이 문제를 직접 겪은 경험·계기·추진경과·기존 성과로 "왜 우리가 하는가"를 입증. 🚫 DON'T: 시장 통계·트렌드·경쟁사 분석(→1-1·2-1), 기존 해결책의 한계 나열(→1-3)을 반복하지 말 것.

이 아이템을 기획하게 된 내부적인 스토리와 현재까지의 준비 과정을 작성.

**작성 유형 판단 (인터뷰 답변 기반으로 자동 선택)**

| 유형 | 조건 | 핵심 메시지 방향 |
|------|------|-----------------|
| A. 대표자 경험 창업형 | 출시 이력 없음 / 예비창업자 | 대표자의 N년 경력·현장 체감 → 아이템 기획 |
| B. 서비스 출시 후 확장형 | 기출시 서비스 보유 | 기존 서비스 성과·지표 → 이번 아이템의 필요성 |

**유형 A — 대표자 경험 창업형 템플릿**
"대표자는 [N년간 X 업계 경험 중] [문제 Y]를 직접 체감했으며, 이를 해결하기 위해 [아이템]을 개발하게 됨."

**유형 B — 서비스 출시 후 확장형 템플릿**
- ■ 소제목: 기존 서비스의 정량적 성과 수치(가입자·거래건수·매출·고객문의 건수 등)를 헤드라인으로 배치
- 세부내용 ①: 기존 서비스 출시 시점·현재 운영 현황·달성 성과를 수치 중심으로 작성
- 세부내용 ②: 기존 서비스에서 발견된 신규 수요·확장 필요성 → 이번 아이템으로 이어지는 논리 구성
- 인터뷰에 수치가 없으면 업종 평균 기준으로 합리적 수치를 직접 산출하여 `(추정)` 표기

### Good Examples

**[바로마크]**
> ■ 대표자가 직접 겪은 워터마크 삽입의 어려움 — 14년 엔터 업계 현장에서 시작됨
> - 대표자는 엔터 업계에 있으며 이러한 워터마크 삽입에 큰 불편을 직접 겪었으며, 이를 해결하기 위해 '바로마크 서비스'를 개발하게 됨.
> - 초기 시장 검증 및 인력비 절감을 위하여 대표가 직접 서비스를 기획 및 개발하며 기초 개발 능력을 보유하게 되었음.

**[올턴 포크맨]**
> ■ 현장에서 직접 느낀 안전하고 효율적인 운반 장비의 필요성
> - 대표자는 과거 휠 제조 및 복원업체에서 이사로 재직 중 지게차의 위험성과 작업 시 문제점을 직접 경험하며 '올턴 포크맨'을 기획하게 되었음.

**[맡길랩 엔터프라이즈]**
> ■ 정기보관물품 400건 돌파, 월평균 10회 이상 기업 고객 문의 쇄도 중
> - '24년 11월, 개인 타깃 셀프 스토리지 서비스 '맡길랩' 출시 운영 중. 3개월만에 정기 보관 물품 400건 이상의 성과 달성.
> - 기업 고객의 '월평균 10회 이상 요청' 문의가 오고 있으나, 개인 대상 서비스로 영업 불가 → 서비스 확대 필요성 절감.

## 1-3. 필요성

**[역할 경계]** ✅ DO: 기존 해결방식(타사·기존 방식)의 구조적 한계를 짚고 → 어떤 솔루션이 필요한지 당위 결론 도출. 🚫 DON'T: 1-1의 시장규모·트렌드 데이터 재나열, 솔루션 기능 상세(→2-2)는 다루지 말 것.

기존 해결 방식의 한계를 지적하고, 어떤 제품/서비스가 필요한지 결론을 작성.

### Good Examples

**[올턴 포크맨]**
> ■ 자동화 도입이 어려운 중소기업, 여전히 지게차 구매/임대
> - 최근 자동화 설비를 도입한 물류센터가 늘어나고 있지만, 이는 중견/대기업에만 해당하는 사례이며, 현실적으로 중소기업이 도입하기에는 아직은 무리인 상황임.
> - 물류 로봇, 물류 자동화 설비 등을 도입하기 위한 비용은 평당 300만 원 이상으로 1,000평 기준 최소 30억 이상의 자금이 필요함. → 비용 문제로 자동화 설비 도입 제한, 지게차 외 대안 부재.

**[이지업워커S]**
> ■ 수입산이 대부분인 시장, 한국 노인들과는 맞지 않는 제품 스펙
> - 기존 시장에서 '준수한' 수준의 제품은 '일본', '독일' 등 수입 제품이 대부분이며, 한국 노인 체형에 맞는 구조는 찾기 어려움.
> - 특히 조절 방식이 복잡하고 수동으로 이뤄져 노인들이 스스로 길이 조정이 어려움.

## 1-4. 문제인식 결론 박스

**문제인식(1-1 ~ 1-3) 마지막에 반드시 1×1 표(박스)를 삽입하여 전체 문제인식을 한 문장으로 요약.**

**작성 규칙**
- 표: 1행 1열 단일 셀 (셀 병합 없음)
- 글자 수: 60~80자 내외 (1~2줄)
- 내용 필수 요소: ① 해결해야 할 핵심 문제 + ② 이를 해결하는 아이템의 핵심 요소
- 문장 형식: 음슴체 ("~이 필요함" / "~로 [문제]를 해결함")
- 강조 처리: 핵심 키워드에 작은따옴표('') 사용

**마크다운 출력 형식**
```
| [결론 문구 60~80자] |
```
(1×1 셀 단일 표)

### Good Examples

> | 이제는 '문서화 역량'이 아닌, '사업 아이템'과 '준비도'로 공정하게 평가받을 수 있는 환경 조성이 필요함. |

> | 정보 과부하로 구매를 포기하는 반려동물 보호자에게, '개체 맞춤 큐레이션'으로 선택 피로를 없애는 커머스가 필요함. |

# 2. 실현가능성

## 2-1. 시장 분석 — 목표 분량: 1,000자 (약 1.5페이지)

**[역할 경계]** ✅ DO: TAM/SAM/SOM 정량·산출근거, 시장 성장률, 타깃 고객 규모로 "시장이 얼마나 크고 자라는가"를 입증. 🚫 DON'T: 1-1의 문제 제기 반복(1-1=왜 문제다 / 2-1=시장이 크다), 자사 경쟁우위 주장(→2-2)은 다루지 말 것.

### 역할
전문 시장 분석가. 아이템과 개발 동기의 맥락을 이어받아 구체적인 시장 데이터를 제시.

---

### 2-1-1. 시장 규모 및 성장성

객관적인 수치나 추정치를 활용하여 시장이 성장하고 있음을 증명. (연평균 성장률 등 언급)

#### Good Examples

**[이지업워커S]**

### 2-1-2. TAM-SAM-SOM (1차 타겟)

전체 시장(TAM), 유효 시장(SAM), 수익가능시장(SOM)을 정의하고, 1차 타겟 시장의 명확한 좌표를 작성.
SOM은 반드시 "타깃 고객 수 × 단가 × 점유율 가정"으로 산출 근거 명시.

#### Good Examples

**[이지업워커S]**
- TAM: 글로벌 보행보조기기 시장 **7.25조 원** (VerifiedMarketResearch 2024)
- SAM: 아시아 보행보조기기 시장 **3.25조 원**
- SOM: 국내 보행보조기기 시장 **1,300억 원** → 당사 1차 타깃

**[맡길랩 엔터프라이즈]**
- TAM: 국내 B2B 스토리지 시장 **18.6조 원** (전국 620만 개 사업체 기준)
- SAM: 수도권 B2B 스토리지 시장 **9.6조 원** (수도권 320만 개)
- SOM: 수도권 1% **약 9.6억 원** ← **산출 근거**: 사업체 3.2만 개 × 평균 연간 보관료 30만 원

**[올턴 포크맨]**
- TAM: 물류 자동화 설비 시장 **5조 원**
- SAM: 물류 자동화 중장비 시장 **2조 원**
- SOM: 물류 지게차 시장 **5,000억 원** → 3,000평 이하 소형 물류센터 3,000개 소

# 4. 기업 구성 — 목표 분량: 1,500자 (약 2페이지)

## 4-1. 기업 구성

**[역할 경계]** ✅ DO: 대표 경력 스토리텔링, 4대 역량축(제작·유통·R&D·수급) 배치, 조직 구성표, 추가고용계획, 외부 네트워크. 🚫 DON'T: 사업 아이템·시장 설명 반복(→1·2장)은 다루지 말 것.

### 역할
인사 조직 전문가. 이 팀이 사업을 성공시킬 이유를 증명.

### 작성 전 사전 분석 (필수)

기업 구성을 작성하기 전, 본문에 작성된 사업 내용을 바탕으로 아래 4가지 역량 축을 먼저 추출. 이후 각 소항목(대표자·기업·조직·고용·네트워크)에 해당 역량이 어떻게 배치되는지 확인하며 작성.

| 역량 축 | 확인 항목 |
|---|---|
| 시제품 제작 역량 | 누가 제품/서비스를 직접 만들 수 있는가 |
| 판매·유통 역량 | 누가 고객을 확보하고 채널을 운영할 수 있는가 |
| R&D 역량 | 누가 기술을 고도화하고 IP를 확보할 수 있는가 |
| 필수 재료·자원 수급 역량 | 원재료·외주·파트너십 등 공급망을 누가 관리하는가 |

> **작성 원칙**: 위 4가지 역량 축이 대표자·팀원·외부 네트워크 중 어딘가에 반드시 배치되어야 함. 공백이 생기면 추가 고용 계획 또는 외부 네트워크로 보완.
