# 원칙
모든 성과·현황을 **"과거 실적 표 + 미래 계획 표"** 쌍으로 제시한다.
- 과거: 이미 달성한 것 → **신뢰도** 증명
- 미래: 같은 형식으로 이어갈 것 → **실행력** 증명

# 적용 규칙
1. 투자 유치: 과거 라운드 표 + 향후 라운드 표 (동일 형식)
2. 매출: 전년 실적 표 + 협약기간 목표 표
3. 특허: 등록 IP 목록 + 출원 예정 IP 목록
4. 인증: 취득 인증 + 계획 인증
5. 고용: 현재 인력 + 채용 계획
6. 과거가 없으면 "관련 경험" 또는 "사전 PoC"로라도 증빙 문단 1개 필수.
7. **매출 과거 항목에 채널별 첫 고객 확보 방법과 고객 검증 데이터(파일럿 n건, 재구매율 등) 포함** — 발표 심사에서 매출 경로(7.7%)·검증(5.1%) 질문이 집중되므로 서류 단계에서 이미 이 수준까지 작성.

# Good Example (합격작 패턴)
```
[과거]                        [미래]
시드 Pre-A (2023, 5억원)       시리즈 A (2026 Q2, 목표 20억원)
 → TIPS + VC 2곳               → 벤치마크: 채널톡 시리즈 B 수준
```

# Bad Example (불합격작 패턴)
- "향후 5년 매출 100억 목표" (과거 근거 없음)
- "CTO 채용 예정" (과거 팀 운영 이력 없음)

# Rubric (LLM 자가 평가)
- [ ] 해당 섹션에 과거/미래 쌍 테이블이 있는가?
- [ ] 과거 항목에 날짜·수치가 구체인가?
- [ ] 미래 항목이 과거의 리듬을 따르는가? (급작스런 10배 점프 아님)
- [ ] 고객 검증 데이터(파일럿 건수·재구매율·NPS 등) 또는 채널별 첫 고객 확보 경로가 과거 항목에 있는가?
