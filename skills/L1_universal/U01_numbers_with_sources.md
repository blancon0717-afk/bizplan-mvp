# 원칙
모든 정량적 주장은 반드시 **출처(source)가 붙은 수치**로 제시한다. 추상적 형용사("압도적", "매우 큰", "폭발적")는 **수치로 대체**한다.

# 적용 규칙
1. 시장 규모 언급 시 **반드시 출처** (예: Statista, 한국통계청, 산업 보고서). 그래프·기사·사진 등 모든 시각자료에도 동일하게 적용한다. 정확한 URL보다 공신력 있는 기관명 표기가 더 중요하다.
2. 성과·실적 언급 시 **측정 방법·표본·기간** 명시.
3. 예측치 언급 시 **근거 가정**(단가 × 물량 × 점유율) 병기.
4. "많은 고객들이 불편을 겪고 있다" 같은 표현은 금지 → "X명 대상 설문에서 Y%가..."로 치환.
5. 페이지당 정성 수식어("완벽히", "압도적") 2개 이하로 제한.

# Good Example (합격작 패턴)
- "국내 근력 보충제 시장은 [2,300억 원] (한국건강기능식품협회 2024) 규모이나, 결합조직 회복 제품은 전체 [0.1%] 미만."
- "당사 제품은 혈중 아미노산 농도가 [15분 내] 피크 (자체 임상 n=[12]명, 2024.3)."

# Bad Example (불합격작 패턴)
- "시장 규모는 매우 크다."
- "많은 고객이 우리 제품을 좋아할 것이다."
- "혈당 억제율 61.5%" (표본·방법·기관 없음)

# Rubric (LLM 자가 평가)
- [ ] 모든 수치에 출처 표기가 있는가?
- [ ] 추상적 형용사가 2개 이하인가?
- [ ] 예측치에 계산 근거가 있는가?

# 완성도 규칙 (절대 준수)

## 금지 표현
- 대괄호 플레이스홀더 절대 금지: `[아이템명 필요]`, `[기존 해결책의 한계: 무엇인가?]`, `[시장규모 입력]`, `[수치 필요]` 등 일체 금지
- 수치 표기 시 대괄호 절대 금지 — 나쁜 예: `[약 15~20%]` → 좋은 예: `약 15~20%`
- `(* 출처 필요)`, `(* 확인 필요)` 등 주석 형태 절대 금지

## 정보 부족 시 처리 원칙
임의로 정보를 만들어내지 말 것. 반드시 아래 우선순위로 처리:

1. **1순위**: 사용자가 입력한 정보에서 추출
2. **2순위**: 공신력 있는 기관의 실제 데이터 + 출처 명시
3. **3순위**: 합리적 추론 + 계산 근거 문장으로 서술

사용자 고유 정보(자체 설문, 자사 실험 데이터)만 피드백 메모(severity=warning)로 보완 요청.

## 완성도 기준
- 외부인이 읽었을 때 완성된 보고서로 보여야 함
- 작성 중이거나 미완성인 느낌을 주는 표현 일체 금지

## 수치 추정 방법 (정보 부족 시)
- 월 고정비 → 업종별 평균 기준으로 직접 산출
  예: 앱 서비스 서버비 월 30~50만원, 인건비 1인 월 350만원
- 시장규모 → 유사 서비스 데이터 또는 인구 기반 산출
- 전환율 → 업종 평균 (SaaS 2~5%, 커머스 1~3%) 적용
- 성장률 → 유사 서비스 초기 성장 패턴 적용

## 절대 금지 표현
- 'OO 추정 필요'
- 'OO 입력 필요'
- 'OO 확인 필요'
- 'OO 미정'
→ 위 표현 대신 반드시 AI가 합리적 수치를 직접 산출할 것
