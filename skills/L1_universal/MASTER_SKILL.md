# 1. 서식 규칙

## 표 서식
- 표 제목: `< 표 제목명 >` 꺾쇠 형식으로 표 상단에 기재, 하단에 `* 출처 :` 주석 필수
- 빈 칸은 `-`로 채움. 헤더 행에 반드시 배경색 적용
- 인건비 산출: `월 N만원 × N인 × N개월 = 합계` 공식 형식 준수
- 고용 수치: 인원 기재 시 `대표자 제외` 또는 `대표자 포함` 괄호 명시 필수

## 이미지 캡션
- 모든 이미지·도식 하단에 `< 설명명 >` 형식 캡션 기재
- AI 생성 이미지는 `(AI 생성 이미지)` 명기, 외부 출처는 반드시 병기

# 2. 수치·출처 처리 규칙

## 정보 부족 시 3순위 처리
1. **1순위**: 사용자가 입력한 정보에서 추출
2. **2순위**: 공신력 있는 기관의 실제 데이터 + 출처 명시
3. **3순위**: 합리적 추론 + 계산 근거 문장으로 서술

## 수치 추정 방법 (정보 부족 시)
- 서버비: 앱 서비스 기준 월 30~50만원
- 인건비: 1인 월 350만원 기준
- 시장규모: 유사 서비스 데이터 또는 인구 기반 산출
- 전환율: SaaS 2~5%, 커머스 1~3% (업종 평균)

## 절대 금지
- `[수치 필요]` `[출처 필요]` `[추정값]` 등 플레이스홀더 본문 삽입 금지
- `(* 출처 필요)` `(* 확인 필요)` 주석 형태 금지
- `OO 추정 필요` `OO 미정` 표현 금지 → 반드시 AI가 합리적 수치 직접 산출

## 근거 제시 4가지 방법
1. 뉴스 기사: 사회적 공감·이슈화 증빙 (문제인식 도입부 활용)
2. 논문·전문서적: 전문가 권위 차용 (주장 강화 도구로만 활용)
3. 잠재고객 인터뷰(FGI): 실제 진행 사진·일자·설문지 함께 제시해야 신뢰도 확보
4. 자체/위탁 실험: 신뢰도 가장 높음. 실험 조건·방법·절차 반드시 병기

# 3. 카테고리별 필수 항목 및 작성 가이드

## Problem 섹션
**3단 구조**: 거시 트렌드 → 구체 문제 → 기존 해결책의 한계

**필수 구성요소 5개** (3문단 이내 모두 포함):
① 문제 정의 → ② 내적 동기(창업자가 왜 이 문제를 선택했는가) → ③ 외적 동기(기사·통계·리포트) → ④ 고객 현황 및 현재 해결책의 한계 → ⑤ 필요 서비스와 혜택

**작성 템플릿**
- 시장 공백: "[시장]은 [규모, 출처]로 성장 중이나, [Y%]가 [기존 카테고리]에 편중된 공급 불균형 상태임"
- 사각지대: "[X명]이 [구체 문제]를 겪고 있으나 적절한 솔루션 없어 [사회적·경제적 비용]이 발생함"
- 대표자: "대표자는 [N년간 X 업계 경험 중] [문제 Y]를 직접 체감했으며, 이 문제가 [타 집단에도] 동일하게 존재함을 확인함"

## Solution 섹션
**3단 기술 원리**: 성분/투입 → 작용 기전 → 결과 효과

**필수 포함**:
- 특허번호·출원 상태 본문 직접 노출 (표에만 숨기지 말 것)
- 경쟁사 3열 기능 매트릭스 (자사만 ○인 행 최소 1개 필수)
- OEM/생산 파트너 구체 기업명 명시

**경쟁사 매트릭스 예시**:
| 항목 | 경쟁 A | 경쟁 B | 자사 |
|---|---|---|---|
| [기능 1] | △ | - | ✓ |
| **[자사 유일 행]** | - | - | **✓** |

**절대 원칙**: "경쟁사 없습니다" 금지 — 즉시 탈락 신호

**외주 제조 시**: 창업자 기여 포인트 반드시 명시 (레시피 설계, QC 기준, 독점 소싱, 공정 특허 중 하나 이상)

## Scale-up / BM 섹션
**수익 모델 1줄 정의**: "누가, 무엇에, 얼마를 지불하는가"를 한 문장으로

**단위경제 표 필수**:
| 항목 | 수치 |
|---|---|
| 객단가 | N원 |
| 건당 마진 | N원 / N% |
| CAC | N원 |
| LTV | N원 |
| LTV/CAC | N배 (3배 이상 권장) |

**비용구조 3분류**: 고정비(인건비·임차·SaaS) / 변동비(재료·물류·광고) / 투자비(R&D·설비)

**마케팅 정량 공식 (필수)**:
파트너 수 × 전환율 × 구매가 = 채널별 예상매출

**BM 원칙**:
- 플랜A + 플랜B 필수 (주력 + 보조 수익원 각 1개)
- BM 3개 이상 금지 — 집중력 부족 신호

## Team 섹션
**서사 구조 필수**: "OOO은 ○년간 ○○에서 ○○을 했고, 이 경험이 이 아이템에서 ○○으로 적용된다"
- 이력서식 나열 금지
- 기술형 프로그램(예창·딥테크): 마케팅 인력보다 기술·R&D 인력 강조

**과거·미래 2단 증명** (Scale-up/Team 섹션):
- 투자·매출·특허·인증·고용 모두 과거표+미래표 쌍으로 제시
- 과거가 없으면 "관련 경험" 또는 "사전 PoC"로 증빙 문단 1개 필수
- 매출 과거 항목에 채널별 첫 고객 확보 방법 + 고객 검증 데이터(파일럿 건수·재구매율) 포함

# 4. 합격 패턴 핵심 (n=739 분석)

## BM 작성 원칙
- 수익 구조는 레이어로 명시할 것 (예: "B2B 라이선싱 + B2C 구독" = 합격, "다양한 수익 창출 예정" = 불합격)
- 수익원 3개 이상 나열 금지 — 집중력 부족 신호. 플랜A(주력) + 플랜B(보조) 구조로 제시

## 공통 금지 패턴
- 마케팅 전략에 예산·효과 수치 미기재
- 요약문에 이미지 없음
- 대표자 이력이 아이템과 무관
- 5년 매출 10배 이상 점프 + 드라이버 없음
- TAM만 거창하고 SOM 도달 경로 부재

## 심사위원 독서 순서
제목 → 요약문 (여기서 탈락 결정 ~50%) → 팀 구성 → 관심 섹션 발췌독
→ 요약문 통과가 최우선. 나머지 섹션은 요약문 이후에 의미 있음

## Problem 섹션 — 실전 패턴

### ① 정량 수치 + 뉴스 기사 도입 (4건 모두 적용)
- [바로마크] "연간 35조 원의 경제적 손실 — 서류 유출은 전체 사례 중 75%, 연간 6조 원 경제적 손실"
- [올턴 포크맨] "지게차 사고 2년간 2,500여 건, 연평균 1,000명 이상 사상자"
- [이지업워커S] "최근 4년간 노인 낙상사고 약 3배 증가, 주요 응급 이송 원인으로 급부상"
- **공통 구조**: 뉴스 기사 이미지 → 통계 수치 → "왜 지금인가" 논리 순서로 전개

### ② 대표자 1인칭 스토리 (4건 모두 적용)
- [바로마크] "대표자는 엔터 업계에 있으며 이러한 워터마크 삽입에 큰 불편을 직접 겪었으며, 이를 해결하기 위해 '바로마크 서비스'를 개발하게 됨."
- [올턴 포크맨] "대표자는 과거 휠 제조 및 복원업체에서 이사로 재직 중 지게차의 위험성과 작업 시 문제점을 직접 경험하며 '올턴 포크맨'를 기획하게 되었음."
- **공통 구조**: "대표자는 [N년간 X 업계 경험 중] [문제 Y]를 직접 체감했으며, 이를 해결하기 위해 [아이템]을 개발하게 됨."

### ③ TAM→SAM→SOM 실제 수치 형식
- [이지업워커S] TAM: 글로벌 보행보조기기 7.25조 → SAM: 아시아 3.25조 → SOM: 국내 1,300억
- [맡길랩] TAM: 국내 B2B 스토리지 18.6조 → SAM: 수도권 9.6조 → SOM: 수도권 1% 9.6억
  - SOM 산출 근거 명시: "사업체 수 3.2만 개 × 평균 연간 보관료 30만 원" (타깃 수 × 단가 × 점유율 형태)
- [올턴 포크맨] TAM: 물류 자동화 설비 5조 → SAM: 물류 자동화 중장비 2조 → SOM: 물류 지게차 5,000억

## Solution 섹션 — 실전 패턴

### ① 경쟁사 3열 매트릭스 — 자사 유일 행 반드시 포함

**[올턴 포크맨]**
| 구분 | 올턴 포크맨 | 고카트 250 | 두산 배터리 지게차 |
|---|---|---|---|
| 원격 조종 | **O** | △(시스템 제어) | X |
| 무지향성 이동 | **O** | O | X |
| 운반 무게 | 1,000kg | 250kg | 1,000kg |
| 가격 | **19,000,000원** | 26,000,000원 | 32,000,000원 |
→ 자사 유일 행: "원격 조종 가능 + 경쟁 대비 최저가" 조합

**[이지업워커S]**
| 구분 | 코지워커 KS-120 | Drive Medical(Nitro) | 현대메딕스 이지업워커S |
|---|---|---|---|
| 타깃 스펙 | 서양 | 서양 | **동양(한국)** |
| 높낮이 조절 | 수동(핀고정) | 수동(레버+당김) | **반자동** |
| 경사면 속도 조절 | 불가 | 불가 | **무게추 방식** |
| A/S 소요 시간 | 15일 | 30일 이상 | **1일 미만** |
→ 자사 유일 행 3개: 동양 체형 특화 + 경사 속도 조절 + 당일 A/S

### ② 기술 원리 3단계 분해 실제 예시
**[올턴 포크맨 — 경사면 속도 조절]**
① 평지: 보행기 평행 → 무게추 중심축 위치 유지 → 브레이크 패드 마찰 없음 → 안정적 가속 가능
② 내리막: 보행기 몸체 앞으로 기울기 → 무게추는 수직 방향 유지 → 앞쪽 브레이크 판 접촉 → 속도 저감

**[바로마크 — AI 자동완성]**
① 파일·수신인 정보 업로드 → ② 인식·분류 AI가 파일-수신인 매핑·워터마크 작성 → ③ 결과 전달·학습 저장 → 수발신 소요 시간 90% 단축

### ③ OEM/생산 파트너 구체 기업명 + 계약일자 명시
**[올턴 포크맨]** 6개 파트너:
- 상주택명자동화설비유한공사 — 구동 모터·드라이브 OEM ('24.11.18)
- 남경하정전자과학기술유한공사 — 리모컨 컨트롤 송수신부 OEM ('24.11.18)
