# Intent
심사위원이 어떤 섹션을 열어도 즉시 핵심을 파악할 수 있도록, 4단계 제목 계층·기호 체계·수치 표기 규칙을 일관되게 적용하여 사업계획서를 작성한다.

---

# 핵심 원칙

1. 세부 항목( - ) 하나에는 단일 사실 또는 단일 논거 하나만 담고, 200자를 초과하지 않는다.
2. 제목 계층은 4단계(대제목 → 중제목 → 소제목 → 항목)를 반드시 순서대로 사용하고 건너뛰지 않는다.
3. 강조는 굵게(Bold)만 허용하며, 밑줄·이탤릭·색상 글자는 사용하지 않는다.
4. 모든 수치에는 단위와 출처를 함께 기재하고, 문서 내 동일 수치는 반드시 일치시킨다.
5. 기본 폰트는 맑은 고딕 12pt, 줄 간격은 160~180%를 유지한다. 문단 사이 간격은 최소 1~2pt 이상 확보하고, 표 셀 내 텍스트는 상하 여백을 확보하여 밀착 금지한다.
6. 문서에는 반드시 페이지 번호를 삽입한다. HWP는 쪽번호 매기기, PPT는 슬라이드 번호 템플릿으로 설정한다.
7. 동일하거나 유사한 표현이 같은 섹션 내 3회 이상 반복되지 않도록 한다. 다른 표현으로 환언할 것.

# 적용 규칙

- [제목 계층] 대제목은 `1. 제목명`, 중제목은 `1-1. 제목명`, 소제목은 `■ 제목명`, 세부 항목은 ` - 내용` 형식을 사용한다. 대제목·중제목은 시스템이 별도 출력하므로 content_segment 안에 절대 쓰지 않는다.
- [기호 체계] `■`는 소제목(캐치프레이즈형), `☑`는 요약 섹션의 체크리스트형 강점 열거, `①②③`은 차별화 요소·단계 나열에 사용한다.
- [content_segment 단위] 각 content_segment 하나는 반드시 `■ 소제목` 1개 + 세부 항목( - ) 2~3개로 구성한다. 평문(소제목 없는 단독 문장) segment 금지.
- [음슴체] 세부 항목( - )의 문장 종결은 반드시 음슴체(`~함`, `~임`, `~됨`, `~있음`)로 작성한다. `~합니다`, `~입니다` 형식 금지. 단, 능동형으로 전환 가능한 문장은 수동형(`~되다`, `~될 수 있음`) 대신 능동형(`~할 예정`, `~할 수 있음`)으로 작성한다.
- [표 서식] 표 제목은 `< 표 제목명 >` 꺾쇠 형식으로 표 상단에 기재하고, 하단에 `* 출처 :` 주석을 반드시 추가한다. 빈 칸은 `-`로 채운다. 표 헤더 행에는 반드시 배경색을 적용하여 가독성을 확보한다.
- [수치 표기] 억 단위는 `숫자 + 억 원`(띄어쓰기), 백만 단위는 `숫자 + 백만원`(붙여쓰기), 천 단위는 쉼표(,) 구분, 수출은 `숫자 + 만 불` 또는 `USD`로 통일한다.
- [이미지 캡션] 모든 이미지·도식 하단에 `< 설명명 >` 형식의 캡션을 기재하고, AI 생성 이미지는 `(AI 생성 이미지)`를 캡션에 명기한다. 외부 출처 이미지는 캡션에 출처를 반드시 병기한다. 삽입한 이미지는 '글자처럼 취급'으로 설정하여 레이아웃 이탈을 방지한다.
- [인건비 산출] `월 N만원 × N인 × N개월 = 합계` 공식 형식을 반드시 준수한다.
- [고용 수치] 인원 기재 시 `대표자 제외` 또는 `대표자 포함` 여부를 괄호로 반드시 명시한다.
- [표 서식] 사업비 집행계획 표에는 '집행기간' 컬럼을 포함하지 않는다. 항목·금액·산출근거·비고 컬럼만 사용한다.

# 문장/표현 템플릿

## 패턴 A: 소제목 + 세부 항목 기본 구조
```
● [[카테고리]] [소제목명]
 - [핵심 사실 또는 근거 — 수치 포함 시 굵게 처리] (* 출처 : [기관명])
 - [보완 설명 또는 당사 대응 방향]
```

## 패턴 B: 차별화 요소 열거 구조
```
① '[차별화 키워드]' [한 줄 요약 문구]
 - 기존 제품 : [기존의 한계 또는 문제점]
 - [자사 제품명] : [자사 기술·방식] → [결과 수치 또는 효과]
```

## 패턴 C: 표 제목 + 출처 주석 구조
```
< [표 제목명] >
                          * [단위 또는 기준 설명]. 발생 [기간] 기준.
| 열1 | 열2 | 열3 | 열4 |
|-----|-----|-----|-----|
| 데이터 | 데이터 | 데이터 | 데이터 |
* 출처 : [기관명 또는 자체 집계]
```

## 패턴 D: 자금 산출근거 구조
```
• [항목명] [단가] × [수량/기간] = [합계]
  예) 홍현희 광고모델 비용 (3개월 모델 + 촬영 비용)
      96,000,000원(정부지원금) + 14,000,000원(현금) = 110,000,000원
```

## 패턴 E: 추진 현황 타임라인 구조
```
[단계명] ([기간])            [단계명] ([기간])
· [세부 활동 1]              · [세부 활동 1]
· [세부 활동 2]      →       · [세부 활동 2]
  ⇒ [단계 결과 요약]           ⇒ [단계 결과 요약]
```
