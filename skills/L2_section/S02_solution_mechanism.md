# Intent
심사위원이 "이 기술/제품이 실제로 작동한다"고 **믿게** 만든다.

# 핵심 원칙
1. **3단 기술 원리 분해**: 성분/투입 → 작용 기전 → 결과 효과
2. **특허번호·출원 상태 본문 직접 노출** (표에만 숨기지 말고)
3. **"문제점 vs 해결기술" 매칭표**
4. **3-4개 차별점에 각각 "■ 헤드라인"** 부여 + 2행 비교
5. **OEM/생산 파트너 구체 기업명** 명시 (실행 가능성)
6. 경쟁사 비교는 **3열 기능 매트릭스** (포터 5 Forces 등 복잡 프레임 금지)
7. **"이 팀이 만들 수 있냐" 증명** — 발표 탈락 원인 중 제품경쟁력(19.3%)·기술(15.8%)·공급망(5.1%)이 상위권. 서류 단계에서 이미 ① 핵심 기술 보유 증거(특허·시제품·테스트 결과 수치), ② 제조·공급망 파트너 확보 현황, ③ MVP/파일럿 성능 수치 — 3가지 모두 포함해 실행력까지 커버.

# 작성 템플릿

## 3단 기술 원리
"[기존 방식]의 [한계]를 극복하기 위해 [핵심 기술 X]를 적용하여 [측정 가능한 개선 Y%]를 구현함. 작동 원리는 ① [성분 투입] → ② [작용 기전] → ③ [결과 효과]의 3단계."

## 특허 기반 신뢰
"[특허번호 10-XXXX-XXXXXXX]를 기반으로 한 [기술명]을 통해 [기능]을 [N%] 향상시킴."

## 차별화 헤드라인 (3-4개)
"■ [헤드라인 1 — 단어 수 5 이내]
 기존: [한계]
 자사: [해결 방식] → [효과]

■ [헤드라인 2]
 ..."

## 경쟁사 3열 매트릭스
| 항목 | 경쟁 A | 경쟁 B | 자사 |
|---|---|---|---|
| [기능/지표 1] | △ | - | ✓ |
| [기능/지표 2] | ✓ | △ | ✓ |
| **[자사 유일 행]** | - | - | **✓** |
| [가격] | [N원] | [N원] | [N원] |

# Good Example (합격작 발췌, 익명화)
> "본 제품은 유리 아미노산(FA) 기반으로 혈액 흡수 시간을 [15분] 내로 단축. 특허 10-2025-XXXXXXX로 보호되는 캡슐화 공정을 통해 위장 분해를 회피. 경쟁사 대비 흡수 속도 [N배], 생체이용률 [M%] 우위."

# Bad Example (불합격작 발췌, 익명화)
> "우리 제품은 혁신적입니다. AI를 활용하여 뛰어난 성능을 제공합니다." (기술 메커니즘 불명, 특허 숨김, 수치 없음)

# Rubric
- [ ] 기술 원리 3단계 분해가 있는가?
- [ ] 특허번호가 본문에 노출되었는가?
- [ ] 3-4개 차별점에 각각 헤드라인이 있는가?
- [ ] 경쟁사 3열 매트릭스에 "자사 유일 행"이 있는가?
- [ ] 생산·제조 파트너 명시되었는가?
- [ ] 시제품·테스트 결과 수치 또는 MVP 파일럿 성능 수치가 포함되어 "이 팀이 만들 수 있냐"를 서류 단계에서 답하는가?

# 외주 제조 시 주의

외주 제조를 활용할 경우 창업자의 기여 포인트를 반드시 명시해야 한다.
- 인정되는 기여: 핵심 레시피·배합 설계, QC 기준 수립, 독점 원재료 소싱, 공정 특허
- **"기획·판매만 담당" 구조는 기술기업 인정 불가** → 심사에서 진입장벽 점수 0점 처리

# 경쟁사 관련 절대 원칙

- **"경쟁사 없습니다" 절대 금지** — 즉시 탈락 신호
- 고객이 현재 문제를 해결하는 모든 수단이 경쟁사: 직접 경쟁사(동일 제품), 간접 경쟁사(대체재), 현상 유지(아무것도 안 함)까지 포함

# 특허 없을 경우 대응

1. KIPRIS(한국특허정보원)에서 선행특허 검색
2. 선행특허 조합으로 자사 기술과 차별점 명시
3. "출원 예정"으로 어필 — "출원 준비 중(예정 시기: 20XX년 X분기)"으로 구체화
