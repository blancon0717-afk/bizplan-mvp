# Intent
심사위원이 "해결할 가치가 있는 문제"라고 **확신**하게 만든다.

# 핵심 원칙
1. **3단 구조**: 거시 트렌드 → 구체 문제 → 기존 해결책의 한계
2. **출처 있는 수치** 최소 2개 (U01 원칙 적용)
3. **"사각지대" 프레이밍** (U02 원칙 적용)
4. **대표자 1인칭 스토리** 또는 **자사 누적 데이터**로 현장성 부여
5. **문제의 파장** — 개인/기업/사회 비용을 수치로
6. **TAM→SAM→SOM 단계 분해** — 발표 심사에서 시장 규모(8.6%) 질문이 집중되므로, 서류에서 이미 SOM 산출 근거(타깃 고객 수 × 단가 × 점유 가정)까지 명시.

# 작성 템플릿

## 패턴 A: 시장 공백 선언
"[시장 분야]는 [규모 X원, 출처]로 급성장 중이나, 제품의 [Y%]가 [기존 카테고리]에 편중된 공급 불균형 상태임."

## 패턴 B: 사각지대 프레이밍
"[인구 X명, 출처]가 [구체 문제]를 겪고 있음에도, 적절한 솔루션이 없어 [기존 대체수단]에만 의존하여 [사회적·경제적 비용 Z]가 발생하고 있음."

## 패턴 C: 트렌드-문제 연결
"[거시 트렌드, 출처] 확산으로 [행위 B] 인구가 급증하며, [미충족 수요 C]에 대한 잠재 수요가 폭발적으로 증가함."

## 패턴 D: 대표자 1인칭
"대표자는 [N년간 X 업계 경험 중] [문제 Y]를 직접 체감했으며, 이 문제가 [타 집단에도] 동일하게 존재함을 확인함."

# Good Example (합격작 발췌, 익명화)
> "국내 근력 보충제 시장은 2,300억 원(한국건강기능식품협회 2024)으로 성장 중이나, 인대·힘줄 등 결합조직 회복 제품은 전체의 0.1% 미만. 연간 스포츠 부상 [수십만 건] 중 [상당 비율]이 결합조직 손상이나, 기존 제품은 근육 회복에 집중되어 있어 회복 사각지대 발생."

# Bad Example (불합격작 발췌, 익명화)
> "고객들이 불편을 겪고 있음. 시장 규모는 매우 큼. 우리 제품은 이 문제를 해결함."
> → 수치 없음 / 출처 없음 / 대표자 스토리 없음 / 사각지대 미제시

# Rubric (섹션 자가 평가)
- [ ] 거시 트렌드 → 구체 문제 → 한계 3단 구조가 있는가?
- [ ] 출처 있는 수치 2개 이상 있는가?
- [ ] "사각지대" 또는 유사 프레이밍이 있는가?
- [ ] 대표자 스토리 또는 자사 데이터가 포함되었는가?
- [ ] 정성 형용사("매우 큰", "많은") ≤ 2회?
- [ ] TAM→SAM→SOM 분해가 있으며, SOM 산출 근거(타깃 고객 수 × 단가 × 점유 가정)가 명시되었는가?

# 좋은 문제의 3가지 조건

1. **큰 문제** — Willing-to-pay가 높은 시장. 불편 수준이 아니라 비용·시간·리스크로 정량화 가능한 고통
2. **나만의 방법론** — 창업자 고유의 해결 접근법. "왜 이 팀이 이 문제를 풀 수 있는가" 설명 가능
3. **명확한 타겟** — 진통제 모델(수요·타깃 명확) 지향. 비타민 모델(있으면 좋은 것)은 초기 스타트업 심사에서 불리

# 필수 구성요소 5개 (3문단 이내 모두 포함)

① 문제 정의 → ② 내적 동기(창업자가 왜 이 문제를 선택했는가) → ③ 외적 동기(기사·통계·리포트) → ④ 고객 현황 및 현재 해결책의 한계 → ⑤ 필요 서비스와 혜택

> 잠재고객 인터뷰 결과 반드시 포함. 창업자 추정("뇌피셜") 금지 — 실제 고객 발화(인터뷰·설문)로 대체.
