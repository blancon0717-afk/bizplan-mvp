# Intent
심사위원이 "이 사업이 돈을 버는 구조가 명확하다"고 **확신**하게 만든다.
발표 탈락 원인 중 수익/비용구조(10.1%)가 상위권 — 서류 단계에서 이미 단위경제까지 제시해 발표 질문을 차단.

# 핵심 원칙
1. **수익 모델 1줄 정의** — "누가, 무엇에, 얼마를 지불하는가"를 한 문장으로.
2. **단위경제(Unit Economics) 명시** — 건당 매출·원가·마진 또는 LTV/CAC 비율.
3. **비용구조 3분류** — 고정비(인건비·임차·SaaS) / 변동비(재료·물류·광고) / 투자비(R&D·설비) 구분.
4. **손익분기점(BEP) 산출** — 월 판매량 또는 구독자 수 기준으로 명시.
5. **가격 책정 근거** — 원가+마진, 경쟁사 비교, 고객 WTP(지불의향) 중 하나 이상.
6. **채널별 수익 기여도** — 채널이 2개 이상이면 각 채널의 매출 비중 표로 제시.

# 작성 템플릿

## 수익 모델 1줄
"[타깃 고객]이 [제품/서비스]를 [구매/구독/사용량] 기준으로 [단가]에 지불하는 [SaaS·유통·라이선스] 모델."

## 단위경제 표
| 항목 | 수치 |
|---|---|
| 객단가(건당 또는 월) | [N원] |
| 변동원가 | [N원] |
| 건당 마진 | [N원 / N%] |
| CAC (고객획득비용) | [N원] |
| LTV (고객생애가치) | [N원] |
| LTV/CAC | [N배 — 3배 이상 권장] |

## 비용구조 분류
| 구분 | 항목 | 월 비용 |
|---|---|---|
| 고정비 | 인건비, 임차, SaaS 툴 | [N원] |
| 변동비 | 재료비, 물류, 광고비 | [N원/건] |
| 투자비 | R&D, 설비 | [N원 (일회성)] |

## BEP 산출
"월 고정비 [N원] ÷ 건당 마진 [M원] = 월 [K건] 달성 시 손익분기. 현재 월 [P건] 판매 중으로 [K-P건] 추가 확보 필요."

# Good Example (합격작 패턴)
> "B2B SaaS 구독 모델: 기업당 월 30만 원. 변동원가 3만 원(API·클라우드), 건당 마진 90%. CAC 15만 원, LTV 180만 원(6개월 평균 유지), LTV/CAC 12배. 월 고정비 1,200만 원 ÷ 마진 27만 원 = 월 45개 사 확보 시 BEP. 현재 12개 사 운영 중."

# Bad Example (불합격작 패턴)
> "다양한 수익 모델을 통해 매출을 창출할 계획입니다." (단가 없음, BEP 없음, 비용구조 없음)

# Rubric
- [ ] "누가 얼마를 지불하는가" 1줄 정의가 있는가?
- [ ] 단위경제(건당 마진 또는 LTV/CAC)가 수치로 제시되었는가?
- [ ] 비용구조가 고정/변동/투자로 분류되었는가?
- [ ] BEP(손익분기 판매량·구독자 수)가 산출되었는가?
- [ ] 가격 책정 근거(원가·경쟁사·WTP 중 하나)가 명시되었는가?

# BM 설계 원칙

- **플랜A + 플랜B 필수** — 주력 수익원(플랜A)과 보조 수익원(플랜B) 1개씩 제시. 플랜B가 없으면 리스크 대응력 부족으로 감점
- **BM 3개 이상 금지** — 수익원 분산은 집중력 부족 신호. 핵심 1~2개에 집중

# 마케팅 정량 효과 계산 (필수)

마케팅 전략에 예산·효과 수치 없으면 감점. 아래 공식으로 예상매출 산출 필수:

**파트너(채널) 수 × 전환율 × 구매가 = 채널별 예상매출**

예) 파트너사 20개 × 전환율 5% × 월 구독료 30만원 = 월 예상매출 300만원

# 자금 조달 논리 구조

반드시 아래 순서로 서술:

1. **총필요자금** — 사업 목표 달성에 필요한 전체 금액 (견적서 기반)
2. **정부지원금 차감** — 이번 지원사업으로 확보되는 금액
3. **부족분 조달방안** — 자기자본 / 투자 유치 / 대출 / 기타 보조금으로 충당 계획 명시
